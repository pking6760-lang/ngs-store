# NGS Store — Android & iOS apps

The NGS Store web app is now packaged as **native Android and iOS apps** using
[Capacitor](https://capacitorjs.com/). The exact same React code runs inside a
native app shell, so there is only one codebase to maintain.

```
src/            ← the app (React) — edit here
dist/           ← web build output (generated by `npm run build`)
android/        ← native Android project (open in Android Studio)
ios/            ← native iOS project (open in Xcode, macOS only)
capacitor.config.json
```

- **App name:** NGS Store
- **App ID (package / bundle id):** `com.ngsstore.app`

## One-time setup

```bash
npm install
```

## The everyday workflow

You edit `src/` exactly as before. Whenever you want the change to show up in the
apps, rebuild the web bundle and copy it into the native projects:

```bash
npm run sync          # build the web app + copy into android/ and ios/
```

Then open the platform you want:

```bash
npm run android       # build, sync, and open Android Studio
npm run ios           # build, sync, and open Xcode (macOS only)
```

## Building an installable Android APK

You need the **Android SDK** (comes with Android Studio). Then:

```bash
npm run build:apk
```

The APK is written to:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

Copy that file to any Android phone and open it to install (enable
"Install unknown apps" for your file manager first). This debug APK is for
testing/sideloading. For the Google Play Store, build a signed **release
bundle** in Android Studio: *Build → Generate Signed Bundle / APK → Android App
Bundle*.

> A ready-to-install **debug APK was already built and delivered** alongside
> this change, so you can test on an Android phone immediately without
> installing any tooling.

## Building the iOS app

iOS builds **require a Mac with Xcode** (Apple's rule, not ours):

```bash
npm run ios           # opens the project in Xcode
```

In Xcode: pick your Apple Developer team under *Signing & Capabilities*, choose a
device/simulator, and press Run. To publish, use *Product → Archive* and upload
to App Store Connect / TestFlight. (You need an Apple Developer account, $99/yr.)

## Native permissions already configured

| Feature | Android | iOS |
|---|---|---|
| Delivery "Use my location" | `ACCESS_FINE/COARSE_LOCATION` | `NSLocationWhenInUseUsageDescription` |
| Barcode scanner (camera) | `CAMERA` | `NSCameraUsageDescription` |
| Internet / Supabase sync | `INTERNET` | (default) |

UPI payment deep links (`upi://…`) open Google Pay / PhonePe / Paytm directly,
and "Open in Google Maps" links open the system maps app — both work natively.

## Known platform differences

These web features degrade gracefully (the app falls back automatically):

- **Fingerprint/Face admin unlock (WebAuthn):** works in the browser/PWA but not
  inside the native WebView. The app falls back to the password login there.
- **New-order browser notifications:** the web Notification API is limited inside
  the native shell. For reliable native push, add
  `@capacitor/local-notifications` / `@capacitor/push-notifications` later.
- **Barcode scanner** uses the web `BarcodeDetector` API — available on most
  Android WebViews; on iOS it falls back to manual barcode entry.

## Still available as a website / PWA

Nothing about the web version changed. `npm run dev` / `npm run build` still
produce the installable PWA exactly as before.
