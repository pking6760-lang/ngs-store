# NGS Store

Quick-commerce grocery project (Blinkit-style) with **two front-ends**:

| Front-end | What it is | Who uses it |
| --- | --- | --- |
| **Customer storefront** | A website (works on iPhone, Android, and desktop browsers) | Your customers |
| **Admin dashboard** | An **Android app** (`.apk`) built from the same code with Capacitor | You / your staff |

> **Demo stage:** data is stored locally in the browser / app (via `localStorage`),
> so the two sync only within the same device. A shared backend (so the admin
> app manages what all customers see, on any device) is the planned next step.

## Project layout

```
index.html            Customer storefront entry
admin.html            Admin dashboard entry (also the source for the Android app)
src/
  App.jsx             Customer storefront
  components/         Storefront components
  admin/              Admin dashboard (Dashboard, Products, Orders, login)
  context/            Cart state
  lib/store.js        Shared data layer (products + orders in localStorage)
  data/products.js    Sample catalog
android/              Native Android project (generated by Capacitor)
capacitor.config.json Capacitor app config (appId: com.ngsstore.admin)
```

## Run the websites (development)

```bash
npm install
npm run dev
# open the printed URL for the customer storefront,
# add /admin.html for the admin dashboard (demo password: admin123)
```

## Build the customer website (production)

```bash
npm run build      # outputs dist/ (deploy this to any static host)
```

## Build the Android admin app (APK)

Requires the Android SDK (platform 34, build-tools 34.0.0) and Java 17+.

```bash
npm run sync:android          # builds the admin bundle into www/ and syncs it
cd android
gradle assembleDebug          # or ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Install the APK on an Android phone by copying it over and opening it
(enable "Install unknown apps" for your file manager/browser first).
