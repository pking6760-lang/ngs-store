# Immortal Pocket — public site (static preview)

Static prototype deployed to Vercel. No build step — these are plain HTML files.

- `index.html` — main site (watch / read), served at `/`
- `admin/index.html` — admin panel, served at `/admin`

## Vercel settings for this folder
- **Root Directory:** `site`
- **Framework Preset:** Other
- **Build Command:** (none)
- **Output Directory:** (leave default)
